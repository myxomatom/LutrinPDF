# Module feature:about

About screen and third-party licenses (E4): version, licence, source code link, privacy policy
and the list of licences generated at build time (ADR 0030).

*Écran « À propos et licences » (E4) : version, licence, lien vers le code source, politique de
confidentialité et liste des licences tierces générée à la compilation (ADR 0030).*
