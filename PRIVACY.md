# Politique de confidentialité — Lutrin

*Dernière mise à jour : 3 novembre 2026*

**Lutrin ne collecte, ne transmet et ne vend aucune donnée.**

- L'application **ne demande pas la permission d'accès à Internet** : elle ne peut
  techniquement rien envoyer. Vous pouvez le vérifier dans les informations de
  l'application ou dans le manifeste publié avec le code source.
- Aucune publicité, aucun traqueur, aucune télémétrie, aucun rapport de crash distant.
- Les seules données enregistrées le sont **sur votre appareil** : liste des documents
  récents et leurs vignettes, dernière position de lecture, préférences, et (à partir de
  la v1.1) l'historique local des actions demandées par un assistant (sans contenu de
  document). Vous pouvez les effacer depuis les paramètres ou en désinstallant l'application.
- Les mots de passe des PDF protégés ne sont jamais enregistrés ni proposés aux gestionnaires
  de mots de passe ; un document protégé apparaît dans les récents (nom, page atteinte), sans
  vignette de sa première page, et son mot de passe est redemandé à chaque ouverture.
- L'application n'accède qu'aux fichiers que vous choisissez (sélecteur système,
  « Ouvrir avec », partage).
- Les liens externes d'un document ne sont ouverts qu'après votre confirmation, par
  une autre application (navigateur) que vous choisissez.

## Assistants IA (v1.1)

Si vous utilisez un assistant (par exemple Gemini) pour piloter Lutrin, c'est
l'assistant qui reçoit les réponses de Lutrin et qui peut les transmettre à un service
en ligne, selon sa propre politique de confidentialité. Pour cette raison :

- la **lecture du contenu des documents** par un assistant est **désactivée par défaut** ;
- l'accès des assistants peut être entièrement désactivé dans les paramètres ;
- un mot de passe de PDF n'est jamais demandé ni transmis par l'intermédiaire d'un assistant.
