# Sécurité

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour une faille de sécurité.
Utilisez le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**
sur <https://github.com/myxomatom/LutrinPDF/security>.

Indiquez la version concernée, l'appareil / la version d'Android, les étapes de
reproduction et, si possible, un PDF de démonstration (sans données personnelles).

## Périmètre

Sont notamment concernés : plantage ou exécution de code via un PDF malveillant,
accès à des fichiers non accordés par l'utilisateur, fuite de données (mot de passe,
contenu, chemins) dans les journaux, contournement des réglages « Assistants IA ».
Les failles de MuPDF lui-même sont aussi à signaler à Artifex ; nous mettrons à jour
la version embarquée.
